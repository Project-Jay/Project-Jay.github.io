About

어떻게 일해왔는가

대학에서 정보통신공학을 전공하고 C++과 C#을 익힌 뒤, 이차전지 검사 소프트웨어 개발자로 커리어를 시작했습니다. 입사 1년차에 단독으로 캔 외관 검사기를 맡아 개발부터 셋업, 현장 대응까지 책임졌던 경험이 지금의 기준을 만들었습니다. 라인이 멈추면 곧바로 손실이 발생하는 환경이었기 때문에, '동작하는 코드'가 아니라 '멈추지 않는 코드'를 써야 한다는 것을 몸으로 배웠습니다.

왜 데이터인가

검사 결과를 JSON으로 직렬화해 상위 서버로 보내는 모듈, SQLite·MariaDB 기반 검사 이력 저장 및 조회 기능을 맡으면서 관심이 자연스럽게 데이터 쪽으로 옮겨갔습니다. 현장에 정말 필요한 것은 한 장의 판정 결과가 아니라, 축적된 이력을 언제든 조회하고 근거로 삼을 수 있는 구조였기 때문입니다.

지금 하고 있는 것

현재는 C# 기반 MES/POP 시스템을 개발하고 있습니다. WPF·WinForms로 작업 단말 화면을 만들고, SQL Server 저장 프로시저와 ADO.NET으로 작업지시·생산실적·재고·출하·검사 이력을 다룹니다. 데이터 정합성 검증, 중복 처리 차단, ERP 연계 같은 작업들은 화려하지 않지만 시스템의 신뢰를 결정하는 부분이고, 저는 그런 일을 오래 잘하고 싶습니다.
